# v1.5.0 · Composer 交互调整

日期：2026-09-02

## 变更

- 移除工作台自定义拖拽上传监听，避免文件拖入网页时被错误拦截或触发浏览器行为。
- 在现有 GPT 聊天 Composer 左上增加工作文件夹选择入口，复用项目原有目录切换流程。
- 将聊天 Composer 左下角“＋”明确用于上传文件，保留照片上传按钮。
- 缩小新建项目 Composer 的输入区和整体留白，降低对话框高度。
- README、旧附件回归脚本和综合 UI 测试同步更新，明确拖拽上传已关闭。

## 维护要求

后续任何 Agent 或开发者接手并修改本项目时，必须遵循根目录 `AGENTS.md`：在 `changelog/` 新建一个独立的 `YYYY-MM-DD-vX.Y.Z.md` 更新文件，并同步更新根目录 `CHANGELOG.md` 索引与 README（如行为或使用方式发生变化）。
