# v1.5.3 · 稳定性与轮询修复

日期：2026-09-02

## 改了什么

- 修复任务重试耗尽后引用块级变量导致的 `ReferenceError`，失败任务现在会正常交给 GPT 决策。
- 浏览器仍连接但 ChatGPT 页面已关闭时，自动在现有浏览器上下文中恢复可用页面。
- 无效的历史源码目录自动回退到项目默认 `source`，并修复两个现有项目的同类损坏目录记录。
- Dashboard 轮询只读取日志文件尾部和最近 40 条 GPT 对话，避免随历史增长反复全量读取。
- 为以上四项行为补充核心回归测试。

## 为什么

避免失败恢复流程崩溃、页面关闭后无法自愈、损坏路径被继续使用，以及长时间运行后轮询开销持续增长。
