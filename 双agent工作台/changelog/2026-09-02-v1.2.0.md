# v1.2.0 — 2026-09-02

## 修复

- 修复 Windows PowerShell 文件夹选择器对中文路径的错误解码。
- 将共享 ChatGPT 页面按完整“发送—等待回复”周期串行化，避免多项目串话。
- 恢复等待中的项目时自动重建浏览器并打开其已保存的 GPT 会话。
- 暂停或删除项目时取消执行；阻止迟到结果覆盖 `PAUSED` 或重建已删除目录。
- 附件由前端假进度改为真实上传、落盘并通过服务端附件 ID 发送。
- 不再执行依赖未满足的任务；依赖阻塞会请求 GPT 重规划。
- 重规划改用新任务列表作为权威来源，允许删除旧的未完成任务。
- 自动重试仅在耗尽次数后写失败记录，避免同一任务同时显示成功和失败。
- 统一执行报告路径解析，兼容带 `.gpt_workspace/` 前缀的路径。
- 在解析之前校验绝对源码路径，并限制项目 ID 与工作区路径越界。
- Dashboard 写入接口拒绝来自非本机 Origin 的浏览器请求。
- 有效 GPT 协议回复会清零协议重试计数。
