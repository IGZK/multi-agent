# v1.6.0 · DeepSeek 派发精简与档位自适应

日期：2026-09-02

## 改了什么

- 精简并强化项目已有的 `workbench-executor` Skill：稳定角色、执行流程和 outbox 协议只维护一份，并加入工作台提示标记 + 合法信封双重启用门槛。
- 同一项目复用一个 DeepSeek Harness 会话，只在首次建立会话时打开执行窗口；后续 Task 不再重复拉起窗口。
- 子任务信封仅携带项目目标/约束摘要和 `current_task`，完整任务列表只保存在 `project_plan.md`；复用会话的提示只通知信封已更新。
- GPT 规划和重规划请求会附带当前 DeepSeek 模型及推理等级：V4 Pro + High/Max 使用较粗任务，V4 Flash + Off/Low 使用更小且包含方法、顺序和验证检查的任务。
- 新增任务列表去重、Skill 首轮/后续提示、档位策略和单窗口复用回归测试。

## 为什么

减少 DeepSeek 输入中的固定协议、完整计划和重复子任务，降低 token 消耗；同时让不同能力档位获得匹配的任务粒度，避免弱模型因说明不足出错，也避免强模型被冗长步骤束缚。
