# v2.0.8 · 全项目排查、边界修复与重复文件合并

日期：2026-09-04

## 改了什么

- 安装、命令、版本和依赖统一到仓库根目录 `package.json` 与锁文件；完整说明统一到根目录 `README.md`。删除应用目录的重复 `package.json`、`README.md` 和 `start.bat`，根批处理与直接 PowerShell 启动共用 `start.ps1`。
- 修复多个 Node 安装并存时启动器取得多个可执行路径，以及 Windows PowerShell 拆散带空格的 `--key=value` 参数；保留参数和退出码透传。
- 用 Windows 命名管道原子锁定项目的真实目录，修复文件锁竞争、目录大小写/联接绕过、日志位置改变导致锁失效。退出时先冻结调度再等待进程清理；停止失败时保留锁，阻止新实例接管仍在写入的数据。
- 修复验证、检查点复制、服务启动、会话创建和 GPT 等待期间暂停/结束/删除后仍派发、回滚或回写状态的问题。命令行、验证和 Harness 清理共用可等待的进程树终止逻辑，清理失败会阻止回滚和删除。
- 检查点核对原源码路径、真实目录、任务与派发信息，拒绝恢复到后来选择的目录；修改源码目录须先暂停，并清除原检查点、派发和会话。加强工作区路径及目录联接校验，防止越界读写和删除后补丁重建项目。
- 修复恢复执行时绕过已有结果或重新选择其他任务的问题；保留原派发和当前可执行任务。修复项目 ID 冲突、对话序号覆盖和单条损坏记录导致整个历史不可读。
- 追加消息持久化排队，在执行/GPT 回合之间发送；暂停时保留，继续后消费；主动给终态项目发新消息才继续对话。停止项目会撤销此前未发送的队列，防止旧消息重新启动它。
- 修复 Harness RPC 持续分片绕过总超时、断流悬挂和 UTF-8 中文分片损坏；修复 GPT 重连空页面、首次提问计数和 CDP 会话清理。校验配置对象、端口冲突和超时溢出。
- 修复前端异步目录选择、附件读取、上传和消息响应串到其他项目；草稿按项目保存。增加中文输入法确认及重复提交保护，保留发送期间新增的文字和附件。
- 修复轮询打断菜单与键盘焦点、删除错误未处理、暂停任务显示滞后、同长度消息不刷新、连续模型保存乱序，以及保存提示被 CSS 隐藏；去重附件渲染与移除逻辑。
- 两套 Dashboard 测试共用随机端口和独立浏览器。有效断言合并后，删除 13 个旧 UI/样例探针及 6 张历史截图；目录选择 API 的 4 个测试文件收敛成 1 个；真实可见执行探针合并进 Runner 自测。合计移除 26 个重复或过时文件。
- 新增启动、后端安全、运行时安全和 UI 状态回归，保留独有覆盖；更新使用说明及 `design-qa.md`。没有新增第三方依赖。

## 为什么

本次从安装入口、控制器、存储、执行器、GPT 桥接、Dashboard 和现有测试逐项检查。基线在真实 Chrome 临时目录清理时出现文件占用失败；进一步复现了暂停后迟到写入、检查点恢复错目录、跨项目异步操作以及启动参数拆分等问题。修复围绕这些根因展开，重复文件合并后仍保留完整安装、启动、维护和测试入口。
