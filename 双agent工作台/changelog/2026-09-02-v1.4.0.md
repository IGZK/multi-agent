# v1.4.0 · GPT 对话附件上传

日期：2026-09-02

## 变更

- 移除新建区上方的“文件夹选择”和“标准模式”上下文栏，保留底部工作目录选择按钮。
- GPT 对话输入框支持拖拽文件；拖拽事件只绑定现有项目的 GPT Composer，不会干扰新建项目任务描述。
- 附件发送时由 ChatGPT 浏览器 Composer 真实上传文件，消息仍通过 GPT 会话发送，不直接交给 DeepSeek。
- 保留原有附件按钮、多文件、照片预览、失败重试和 50MB 限制。
- README 补充拖拽上传用法；新增 UI 回归覆盖拖拽附件与服务端附件转交。

## 维护要求

后续任何 Agent 或开发者接手并修改本项目时，必须遵循根目录 `AGENTS.md`：在 `changelog/` 新建一个独立的 `YYYY-MM-DD-vX.Y.Z.md` 更新文件，并同步更新根目录 `CHANGELOG.md` 索引与 README（如行为或使用方式发生变化）。
