# v2.0.5 — 空闲启动不再唤起 GPT

日期：2026-09-04

## 改了什么

- 删除主入口空闲启动时调用 GPT 预热的逻辑，以及没有其他调用方的 `warmup()` 和 `gpt.prewarm` 配置。
- GPT 浏览器由项目执行、消息发送或主动打开操作按需启动；保留已有未完成项目的自动恢复。
- 更新 README 的首次登录、启动行为和配置说明，版本更新为 2.0.5。

## 为什么

此前即使没有运行项目，启动工作台也会自动导航到 ChatGPT，导致仅查看工作台时弹出 GPT 窗口。移除触发源，让空闲查看不再启动浏览器。

## 验证

- `npm test` 通过：82 项回归测试、23 项协议检查、7 项 GPT Bridge 检查及文件夹选择器自测，包含隔离真实 Chrome 的按需连接、并发唤起和重连测试。
- 本次未修改 Dashboard。
