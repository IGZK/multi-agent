# v1.3.0 · Harness 风格新建对话框

日期：2026-09-02

## 变更

- 将新建项目区域收敛为大尺寸底部 Composer：任务描述、工作目录选择、模型/推理选项和圆形发送按钮。
- 新用户默认使用浅色主题，保留右上角深浅色切换。
- 移除新建流程中的“项目名称”和“分类”字段；项目名称由工作目录名或任务首行自动生成。
- 左侧项目列表改为按源码工作目录分组，不再提供手工分类按钮。
- 保留旧项目的显示名、归档和删除能力；项目详情不再显示手工分类。
- 增加项目列表 `source_dir` 数据并补充后端自动命名回归测试。
- README 同步更新新建流程与项目分组说明。

## 维护要求

后续任何 Agent 或开发者接手并修改本项目时，必须遵循根目录 `AGENTS.md`：在 `changelog/` 新建一个独立的 `YYYY-MM-DD-vX.Y.Z.md` 更新文件，并同步更新根目录 `CHANGELOG.md` 索引与 README（如行为或使用方式发生变化）。
