# 更新日志索引

每次更新使用独立文件记录，统一存放在 [`changelog/`](changelog/) 目录。

## 命名标准

```text
YYYY-MM-DD-v主版本.次版本.修订版本.md
```

例如：`2026-09-02-v1.2.1.md`。

同一天发生多次更新时，每次递增修订版本号，禁止覆盖之前的日志文件。最新记录排在最前。
