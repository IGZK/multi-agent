# 项目接手规则

这些规则适用于任何修改本目录的 Agent 或开发者。

1. 每次修改代码、配置、界面或文档，都必须在 `changelog/` 新建一个独立日志文件，禁止覆盖或续写旧日志。文件名统一为 `YYYY-MM-DD-vX.Y.Z.md`；同一天多次更新时递增修订版本号。
2. 新日志必须写明版本、日期、“改了什么”和“为什么”，并把链接添加到根目录 `CHANGELOG.md` 索引顶部。
3. 行为、启动方式、配置项或目录结构变化时，同步更新 `README.md`。
4. 优先修根因并保持实现简单；无实际调用方的兼容层、探针和抽象应删除，不新增无必要依赖。
5. 修改后至少运行 `npm test`；涉及 Dashboard 时再运行 `node test/verify-task009.mjs`。无法运行的检查必须在交付说明和更新日志中注明。
6. 不编辑或提交 `browser-profile/`、`logs/` 以及无关项目的 `projects/` 数据。
7. 暂停、删除和路径校验属于安全边界；相关改动必须有回归测试。
